# API reference

Rendered **live** from the OpenAPI spec generated by
[`meshbee-server`](https://github.com/fablab-imperia/meshbee-server), read straight from its `main`
branch. Your browser fetches it when this page loads, so what you see below is always the current
contract — there is no copy kept in this repository to fall out of date, and no docs rebuild to
wait for.

The spec itself lives at
[`api/openapi.json`](https://github.com/fablab-imperia/meshbee-server/blob/main/api/openapi.json)
in that repository, where it is generated with `make openapi`.
