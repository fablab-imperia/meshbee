# Roadmap

La pianificazione vive in due posti, e la divisione è voluta.

Gli **obiettivi che attraversano più repository** stanno sulla
[bacheca di progetto dell'organizzazione](https://github.com/orgs/fablab-imperia/projects),
raggruppati per il campo `Release`. Una release è qualcosa che puoi indicare in un campo: di
solito richiede modifiche a firmware, server e app insieme, quindi non può appartenere a un
singolo repository.

Le **milestone dei singoli repository** significano esattamente una cosa: *il prossimo tag di quel
repository*. Se non esce nel prossimo tag di quel repo, non è in quella milestone.
