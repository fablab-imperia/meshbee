# Roadmap

Planning lives in two places, and the split is deliberate.

**Cross-repo goals** live on the [org project board](https://github.com/orgs/fablab-imperia/projects),
grouped by the `Release` field. A release is a thing you can point at in a field — it usually
needs firmware, server, and app changes together, so it can't belong to any single repo.

**Per-repo milestones** mean exactly one thing: *that repo's next tag*. If it doesn't ship in the
next tag of that repo, it isn't in that milestone.
